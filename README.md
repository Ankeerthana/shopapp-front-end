# 🛍️ ShopApp - E-Commerce Clothing Website

E-commerce clothing website frontend built with React.js

## 🛠️ Tech Stack
- React.js 18
- Redux Toolkit
- Tailwind CSS 3
- React Router v6
- Axios
- Razorpay Payment Integration
- Google Maps Integration

## ✨ Features
- Beautiful responsive UI
- Product browsing and search
- Filter by category
- Shopping cart
- Checkout with Razorpay payment
- User registration and login
- Order history
- Store locator with Google Maps

## 🔗 Backend Repository
https://github.com/Ankeerthana/shopapp-backend

## 🔧 Run Locally
npm install
npm start
